# Лапка Надії

Лендінг для притулку тварин, створений за допомогою HTML, CSS та JavaScript.

Сайт призначений для людей, які хочуть знайти домашнього улюбленця та дізнатися більше про усиновлення тварин.

Найскладнішими частинами роботи були адаптивна верстка, створення JavaScript-функцій та публікація сайту на GitHub Pages.
